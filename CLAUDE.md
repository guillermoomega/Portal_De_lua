# Proyecto: Sitio web para Terapeuta Holística (Portal De Lúa)

## Descripción general
Página web para una terapeuta holística. El objetivo es generar confianza, presentar
a la terapeuta y sus servicios, y facilitar que las personas agenden una consulta.

## Stack técnico
- HTML5 + CSS3 + JavaScript vanilla (sin frameworks)
- Estructura modular: cada sección en su propio archivo/componente, pensado para
  poder armar la página completa más adelante uniendo secciones
- Responsive (mobile-first)
- Sin dependencias externas salvo Google Fonts si hace falta

## Estructura de secciones (para el sitio completo, a futuro)
1. Hero / Portada
2. Sobre mí
3. Servicios / Terapias
4. Testimonios
5. Preguntas frecuentes
6. Contacto / Agendar turno
7. Footer

## Guía de estilo
- Paleta: tonos tierra, verdes suaves, beige, blanco roto. Evitar colores estridentes
  o estética "corporativa/tech".
- Tipografía: legible, cálida, con un toque orgánico (nada de fuentes muy técnicas).
- Mucho espacio en blanco, diseño limpio y sereno.
- Imágenes/placeholders relacionados a naturaleza y bienestar.
- Tono general: calma, profesionalismo, cercanía humana.

## Reglas de trabajo
- Vamos a construir el sitio sección por sección, una por vez.
- Cada sección debe quedar en su propio archivo (HTML parcial + CSS específico si aplica),
  para poder integrarlas después sin romper nada.
- Usar variables CSS (custom properties) para colores y tipografías, para mantener
  consistencia entre secciones.
- No avanzar con secciones que no se pidan explícitamente en el mensaje.
